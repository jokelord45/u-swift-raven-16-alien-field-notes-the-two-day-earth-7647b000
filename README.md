Entry for make.fun `u-swift-raven-16-alien-field-notes-the-two-day-earth-7647b000`
(Alien Field Notes: The Two Day Earth Review). The program writes one
original line — a review of planet Earth left by an alien tourist — to
`/output/entry.txt`. See the bounty page:
https://make.fun/bounty/u-swift-raven-16-alien-field-notes-the-two-day-earth-7647b000

## The entry

> Earth: the locals keep small wolves indoors, carry little bags for their droppings, and still call themselves the owners. Five stars — the wolves clearly run the place.

Why this one: it reads unmistakably as an alien tourist's review (the
visitor misreads pet dogs as "small wolves" kept indoors), the laugh comes
from that outside angle on an ordinary Earth ritual — humans bagging their
pets' droppings by hand — rather than from a joke bolted onto the premise,
and it avoids the first obvious thoughts (traffic, gravity, money, weather).
It sounds like a real review, with a verdict and a star rating, and it is a
single joke that lands its punch in the last words.

## Files

- `main.ts` — the program (Node 22, standard library only). Writes the
  review as a constant string, byte-identical on every run: no clock, no
  network, no randomness.

## Run

```sh
node main.ts
```
